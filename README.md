One image that sums up Tuesday 24 November 2026 world news: 28 verified stories — from Nvidia's Huang comeback to COP31's collapse — drawn by a Python program into a 1024x1024 front page.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`).
The program draws the front page with Pillow when it is available, and
otherwise copies the pre-rendered `entry.png` shipped in this repository,
which this same program produced — so both runs always write the same bytes.

## The image

A newspaper front page: masthead, lead story (Nvidia reinstates Jensen
Huang as CEO, shares +31%), two secondary stories (COP31 collapses, Russia's
biggest air assault on Ukraine), an 18-story grid, plus an "also today"
ticker and a UTC timeline. Every story was verified against real reporting
published on 24 November 2026 (Reuters, CNN, WSJ, Times of India, Newsreel,
Al Jazeera).
